# Contributing

Contributions are welcome. Keep probes read-only, structured, timeout-bounded, and locale-independent. Never add telemetry, automatic privilege escalation, shell evaluation, credential inspection, or implicit extraction/execution.

1. Fork and create a focused branch.
2. Add meaningful fixtures/tests for parser and failure paths.
3. Run `scripts/quality` on Omarchy 4.0.x.
4. Explain any new command, network behavior, optional dependency, or permission need in the pull request.

Do not submit this project to the Omarchy marketplace on the maintainer's behalf.
